Integration Google Sheets Sync / Export / Import

What this module does

Adds a complete Google Sheets integration layer in Odoo. After configuring your Google credentials, you can create a connector record for a spreadsheet, define a worksheet, map Odoo fields to columns, and then: export Odoo data to Sheets, import changes back into Odoo, or run scheduled sync jobs. The module supports audit-friendly operations through logs/status so teams can track sync results.

Two-way Data Exchange
Export Odoo records to Google Sheets and import sheet edits back into Odoo with controlled mappings.
Field Mapping & Templates
Define column headers, map Odoo fields, and reuse connector templates for consistent exports/imports.
Automation & Logs
Run sync manually or on a schedule, with status/log tracking for visibility and troubleshooting.

Configuration

Set up Google credentials and connect your spreadsheet/worksheet to Odoo with field mappings.

  1. Create a Google Cloud Project and enable the Google Sheets API.
  2. Create credentials (recommended: Service Account) and download the JSON key.
  3. Share your target Google Sheet with the service account email (Editor access).
  4. In Odoo, open Google Sheets Connector and upload/configure the credentials.
  5. Create a connector: set Spreadsheet ID, Worksheet, and define your field-to-column mappings.
  6. Run Export (Odoo → Sheets) or Import (Sheets → Odoo). Optionally enable Scheduled Sync.
Note: Ensure the Google Sheet is shared with the correct service account email, and verify the worksheet name matches exactly. If permissions are missing, export/import actions will fail.
